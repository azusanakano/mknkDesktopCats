# ゆりちゃん ＆ オニャンコポン v1.9.3

ネコシステム社 / mknkDesktopCats

今回添付されたゆりちゃん・オニャンコポンのJPEG 2枚へ、歩く画像を差し替えたWindowsアプリです。各猫8コマを左上から行順に使い、座る・眠る・伸び・前足上げ・ジャンプ・見回す動作と、従来の速度・設定を引き継ぎます。

ご指定のv1.8.1そのものは取得できなかったため、取得できたv1.9.2を基にv1.9.3として作成しています。v1.9.2で保持されていた休息画像と動作コードを維持し、歩行画像の取り込みと版表示を更新しています。

## バージョンの確認

- ダウンロードしたZIPと展開フォルダー：`mknkDesktopCats_v1.9.3_Windows_x64`。
- 起動中：猫または通知領域アイコンを右クリックして「バージョン情報…」。`バージョン: 1.9.3` と表示します。右クリックメニューの上部・アイコンのヒントにも表示します。
- 起動せず確認：`mknkDesktopCats.exe` を右クリック→「プロパティ」→「詳細」。製品バージョンは `1.9.3`、ファイルバージョンは `1.9.3.0` です。
- 展開フォルダー内の `VERSION.txt` にも `1.9.3` を記載しています。

EXE名は設定と自動起動の互換性のため `mknkDesktopCats.exe` のままです。

## 起動

1. 旧版を起動中なら、通知領域のアイコンを右クリックして「終了」。
2. ZIPをすべて展開します。
3. `mknkDesktopCats.exe` をダブルクリックします。

Windows 10 / 11の64bit（x64）向けです。インストール不要で、画像はEXEに内蔵しています。EXE単体で使えます。

## 操作

| 操作 | できること |
| --- | --- |
| 猫を左ドラッグ | 好きな位置へ移動 |
| クリック | 前足を上げて、ハートで反応 |
| ダブルクリック | ジャンプして、ハートで反応 |
| 猫または通知領域アイコンを右クリック | 大きさ・速さ・一時停止・各猫の表示・バージョン情報・終了 |

猫が見つからないときは、通知領域の隠れたアイコンも確認し、表示設定と「2匹を呼び戻す」を使ってください。

## 復元した動作

2匹が自分で歩いたり、座ったり、眠ったり、伸びをしたりします。右クリック→「ゆりちゃんの動作」または「オニャンコポンの動作」から「座る」「眠る」「伸びをする」などをすぐ試せます。選んだ動作が終わると、再び自分で行動します。前足を上げる・見回す・ジャンプも復元しました。休んでいる間はその場にとどまり、時間がたつと次の行動に移ります。眠った後は伸びをします。

座る・眠る・伸びなどは以前の原画から復元した各1枚の姿勢です。歩行のような複数コマの動きではなく、姿勢を切り替えて表示します。ジャンプでは全身を上下に移動します。

以前の原画に合わせた休息姿勢のため、現在の歩行画像とは毛の描写・顔の向きに差があります。原画の全身を含む範囲から切り出し、旧版のグリッドで切れていた耳や前足を収めています。

## 8コマの歩行

ゆりちゃんは2048×1024、オニャンコポンは2048×1012のJPEGです。どちらも4列×2行の8コマを、左上から右へ、次の行へ、F01→F02→…→F08→F01の順に再生します。緑の背景から透明度を作り、左向きは全身画像の左右反転で表示します。

各列512px幅の固定範囲を、猫ごと・上下段ごとに定めた行原点から切り出します。猫の全身を含む各コマに透明余白を加えて512×512へ収め、全16コマに同じ倍率425/512を適用して、従来の425×425キャンバスへ取り込みます。切り出し座標と処理内容は `preview/reference-import.json` に記録しています。

猫の姿勢や足運びは添付画像のままです。脚だけの変形、コマごとの位置合わせ、中間姿勢の追加は行っていません。表示用画像には透明化と全身の縮小が入るため、原画と同じRGB値・解像度ではありません。原画JPEG自体は再圧縮せず、そのまま `source/art_source/reference` に同梱しています。

| 速さ | 1コマの目標時間 | 1周の目標時間 |
| --- | ---: | ---: |
| ゆっくり | 300ms | 2.4秒 |
| ふつう | 150ms | 1.2秒 |
| 元気 | 100ms | 0.8秒 |

歩行中は、コマを表示している間も猫のウィンドウを移動します。画像の切替と移動を分け、位置の更新は33ms間隔を要求しています。実際の間隔はWindowsの負荷に依存します。タイマーが遅れてもコマは飛ばさず、停止・非表示・ドラッグ中は、歩行と休息の両方で現在の姿勢と残り時間を保持します。

速度と移動量はアプリの設定値です。歩行画像自体を描き直したり中間姿勢を足したりしていないため、原画にある姿勢差やF08からF01へのつながりはそのまま見えます。透明度は緑背景から推定しており、原画JPEGの輪郭にある緑かぶりや圧縮の影響を完全に取り除く保証はありません。

## 更新と設定の引き継ぎ

旧版を終了して同じ場所のEXEを差し替えると、以前の設定を引き継げます。設定保存先は `%APPDATA%\mknkDesktopCats\settings.ini` です。保存済みのドラッグ位置も保持し、複数モニターでは保存位置のモニターを基準に画面内へ収めます。

別フォルダーへ移す場合は新しいEXEを起動し、「Windowsと同時に起動」をいったん解除して再設定してください。EXE名、アプリ識別子、自動起動の値名、ネコシステム社ブランドは継続しています。

同梱の `mknkKotaroChako_1.0.0` は既存の小太郎・チャコさん版です。

## 確認範囲

ビルドと検証の結果は `BUILD-REPORT.txt`、再ビルド用のソースは `source` にあります。歩行16枚は今回のJPEGから更新し、休息・反応12枚と動作コードはv1.9.2から引き継ぐ構成です。歩行・休息の全14枚を左右分キャッシュし、同じ姿勢・位置では画像を再転送しない構成です。

Windows実機での起動・操作とCPU使用率の測定は、この作成環境では未実施です。
