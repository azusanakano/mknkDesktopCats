# mknkDesktopCats v1.1.0

ゆりちゃんとオニャンコポンの歩行を、各4枚から8枚に増やした更新版です。

1. 起動中の猫アプリを右クリックし、「終了」を選びます。
2. ZIPを展開し、これまでの場所の `mknkDesktopCats.exe` を新版に置き換えます。
3. `mknkDesktopCats.exe` を実行します。インストールは不要です。

Windows 10 / 11（64-bit x64）対応。右クリックメニューと通知領域の説明に `v1.1.0` を表示します。

歩行画像は全身を一枚ずつ切り替えます。通常速度の一周は従来と同じ600msで、画像の間隔を150msから75msにしました。サイズと左右反転を準備した画像キャッシュ、位置だけを動かす更新、停止中の再描画の省略で負荷を抑えます。

設定保存先、アプリ名、自動起動の登録名は従来と同じです。自動起動を使用している場合は、以前と同じフォルダーに置き換えてください。

詳しい変更・検証範囲・画像圧縮結果は `CHANGELOG.md`、歩行の比較動画は `preview/walk-comparison.mp4`、ソースは `source/` にあります。
