# ゆりちゃん ＆ オニャンコポン v1.8.0

ネコシステム社 / mknkDesktopCats

添付されたゆりちゃん・オニャンコポンの8コマ画像で、2匹がデスクトップを歩くWindowsアプリです。

## 起動

1. 旧版を起動中なら、通知領域のアイコンを右クリックして「終了」。
2. ZIPをすべて展開します。
3. `mknkDesktopCats.exe` をダブルクリックします。

Windows 10 / 11の64bit（x64）向けです。インストール不要で、画像はEXEに内蔵しています。EXE単体で使えます。

## 操作

| 操作 | できること |
| --- | --- |
| 猫を左ドラッグ | 好きな位置へ移動 |
| クリック／ダブルクリック | ハートで反応 |
| 猫または通知領域アイコンを右クリック | 大きさ・速さ・一時停止・各猫の表示・終了 |
| 「クリックをすり抜ける」 | 猫の下のウィンドウを操作。解除は通知領域アイコンから |
| 「2匹を呼び戻す」 | 2匹を画面内へ戻し、足元の高さをそろえる |
| 「全画面中は隠す」 | 全画面アプリの使用中に自動で隠す |
| 「Windowsと同時に起動」 | ログイン時の自動起動を設定 |

猫が見つからないときは、通知領域の隠れたアイコンも確認し、表示設定と「2匹を呼び戻す」を使ってください。

## 8コマの歩行

各画像を4列×2行の固定セルに分け、左上から右へ、次の行へ、F01→F02→…→F08→F01の順に再生します。左向きは全身画像の左右反転です。原画の姿勢とセル内の位置、元の透明度を使います。

| 速さ | 1コマの目標時間 | 1周の目標時間 |
| --- | ---: | ---: |
| ゆっくり | 300ms | 2.4秒 |
| ふつう | 150ms | 1.2秒 |
| 元気 | 100ms | 0.8秒 |

コマを表示している間も猫のウィンドウを移動します。画像の切替と移動を分け、位置の更新は33ms間隔を要求しています。実際の間隔はWindowsの負荷に依存します。タイマーが遅れてもコマは飛ばさず、停止・非表示・ドラッグ中は現在のコマを保持します。

速度と移動量はアプリの設定値です。歩行画像自体を描き直したり中間姿勢を足したりしていないため、原画にある姿勢差やF08からF01へのつながりはそのまま見えます。添付PNGは再圧縮していません。

## 更新と設定の引き継ぎ

旧版を終了して同じ場所のEXEを差し替えると、以前の設定を引き継げます。設定保存先は `%APPDATA%\mknkDesktopCats\settings.ini` です。保存済みのドラッグ位置も保持し、複数モニターでは保存位置のモニターを基準に画面内へ収めます。

別フォルダーへ移す場合は新しいEXEを起動し、「Windowsと同時に起動」をいったん解除して再設定してください。EXE名、アプリ識別子、自動起動の値名、ネコシステム社ブランドは継続しています。

同梱の `mknkKotaroChako_1.0.0` は既存の小太郎・チャコさん版です。
