# このプロジェクトの変更時に守ること

2026-09-13、ユーザーは新しい8フレームJPEGの2枚への差し替えを依頼した。v1.8.1では今回の添付を原画とする。v1.8.0のPNG素材指定は今回の依頼で置き換えられた。

- ゆりちゃん：art_source/reference/yuri_walk_sheet.jpeg。SHA256: 78e670d6afe8cb87643abfe1c37089a4c433bcc639a6b40932921d4de5ff0bbe。
- オニャンコポン：art_source/reference/onyankopon_walk_sheet.jpeg。SHA256: 555c51736a7b7078ab4c77686633d805a2b527367853ad58a2ab6d900f808ac2。
- 両方1536×768 RGB、4列×2行。384×384の固定セルで左上から行順F01〜F08。
- 原画JPEGのバイト列、デコード後のRGB、姿勢、セル内位置を保持する。描き直し、中間画像、部位変形、各コマごとの位置補正はしない。
- JPEGはアルファがないため、画像取り込み時に黒背景を推定してアルファだけを作る。猫の暗い模様を一律の黒色キーで除去しない。推定の限界は説明する。
- 原画または取り込み座標の変更は、ユーザーが新たに依頼した場合に限る。通常の修正では原画ハッシュの検査を解除しない。
- 2匹の初期位置・呼び戻し位置は固定の猫別接地位置を使い、見た目の地面をそろえる。個別フレームはずらさない。保存済みのドラッグ位置は保持する。
- reference_walk.hが2匹のコマ再生を所有する。クリック・別行動・速度変更で別画像へ切り替えない。
- 速度と移動量は設定値であり、原画から実測した物理量として説明しない。
- ブランド変更でEXE名、設定パス、アプリ識別子や自動起動キーを変更しない。
- バイナリ更新時はbash build.shとbash tests/run_tests.shを実行し、プレビューも再作成する。
- Windows実機を試していなければ未確認と記載する。
