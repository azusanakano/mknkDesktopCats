# mknkDesktopCats

ゆりちゃんとオニャンコポンがWindowsデスクトップを歩き回る、軽量なデスクトップペットです。

## 主な機能

- 2匹が独立して歩く、走る、座る、眠る、伸びる、前足で遊ぶ、跳ぶ
- 近くで出会うと向き合ってハートを表示
- 猫を左ドラッグして好きな場所へ移動
- クリックで反応、ダブルクリックでジャンプ
- 表示、停止、クリック透過、大きさ、速さを右クリックメニューから変更
- マルチモニター対応
- 全画面アプリ使用中の自動退避
- Windowsログイン時の自動起動（任意）
- 設定と最後の位置を自動保存
- ネットワーク通信、広告、解析、管理者権限、外部ランタイムは不要

## 対応環境

- Windows 10 / 11（64-bit、x64）

## ビルド

このリポジトリの `build.sh` は、GCC/binutilsがPE32+出力を扱えるLinux環境とNode.js、Sharpを使います。生成された猫素材はクロマキー除去、境界色補正、RLE圧縮を経て実行ファイルへ直接埋め込まれます。

```bash
./build.sh
./tests/run_tests.sh
```

出力は `dist/mknkDesktopCats.exe` です。
