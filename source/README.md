# mknkDesktopCats v1.1.0

ゆりちゃんとオニャンコポンがWindowsデスクトップを歩き回る、軽量なデスクトップペットです。

## 主な機能

- 2匹が独立して歩く、走る、座る、眠る、伸びる、前足で遊ぶ、跳ぶ
- 近くで出会うと向き合ってハートを表示
- 猫を左ドラッグして好きな場所へ移動
- クリックで反応、ダブルクリックでジャンプ
- 表示、停止、クリック透過、大きさ、速さを右クリックメニューから変更
- マルチモニター対応
- 全画面アプリ使用中の自動退避
- Windowsログイン時の自動起動（任意）
- 設定と最後の位置を自動保存
- ネットワーク通信、広告、解析、管理者権限、外部ランタイムは不要

## 対応環境

- Windows 10 / 11（64-bit、x64）

## ビルド

このリポジトリの `build.sh` は、GCC/binutilsがPE32+出力を扱えるLinux環境とNode.js、Sharpを使います。生成された猫素材はクロマキー除去、境界色補正、RLE圧縮を経て実行ファイルへ直接埋め込まれます。

```bash
./build.sh
./tests/run_tests.sh
```

出力は `dist/mknkDesktopCats.exe` です。

## v1.1.0 の歩行アニメーション

- 各猫の歩行を4枚から8枚へ変更。全画像は16枚/匹です。
- 歩行フレームIDは `0,12,1,13,2,14,3,15`。座る・眠る・伸びる・遊ぶ・跳ぶ・見回す・走る画像のID `4..11` は維持しています。
- 速度「ふつう」は600ms/周・75ms/枚、「ゆっくり」は1200ms/周・150ms/枚、「元気」は400ms/周・50ms/枚です。
- 行動判断は元の50ms刻み。描画タイマーは25msを目標とし、経過時間で処理を進めます。実際の描画頻度はWindowsのスケジューリングに依存します。
- 完成した全身画像を使い、鼻先・接地ラインをそろえています。二重像を作るクロスフェードや実行時の脚の変形はありません。
- サイズ変更時に、8枚×左右2方向の歩行画像を各猫について準備します。通常サイズ224pxで合計6.125MiBのキャッシュを使用します。確保できない場合は変更した画像だけを拡大縮小する処理に戻ります。
- 同じ画像で位置だけ変わる場合は、[MicrosoftのUpdateLayeredWindow仕様](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-updatelayeredwindow)に従って画像の再転送を省略します。表示内容も位置も同じなら描画を省略します。
- PNGの圧縮はビルド前に済ませています。再ビルド時の画像生成・外部画像圧縮サービス・APIキーは不要です。

追加テストは速度ごとの8枚再生、ループの境界、移動補間、3サイズ×2方向のキャッシュ、位置だけの更新、ハート表示、一時停止、非表示を検証します。描画テストはAPIスタブを用いたホスト上の検証です。Windows実機での起動・CPU使用率の測定は未実施です。

添付ZIPの別アプリ `mknkKotaroChako_1.0.0/` は元の内容を収録しています。
