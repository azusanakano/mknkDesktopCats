# 復元した旧版の動作原画

`yuri_green.png` と `onyankopon_green.png` は、復元できた v1.3.1 の `source/art_source/` に入っていた原画を、そのままコピーしたものです。元ファイルの PNG バイト列を変更していません。

- ゆりちゃん SHA256: `772171219af97671b62e5d0ae758aca1edf29dbce4e393db5bad31d79d482307`
- オニャンコポン SHA256: `781c359d466ae83fa1521149ec5c951e1ebe2314d39e3e9cd8f3a39a09b614a5`

この原画から、座る・眠る・伸び・前足を上げる・ジャンプ・見回す姿を復元します。新しい歩行8コマには使用しません。

旧ランタイムの256px固定マスでは、伸びの前足やジャンプ・見回しの耳／尻尾がマスをまたいで切れていました。今回の取り込みは `tools/import_rest.mjs` の明示的な矩形で全身を切り出し、旧版と同じ緑背景除去を行います。425pxのキャンバスに全身を等率で拡大・配置し、接地位置を349pxに合わせます。個々の脚の変形や新規描画は行いません。固定表示倍率はゆりちゃん1.025、オニャンコポン1.08です。

毛の模様・描画の質感は旧原画のままなので、今回の歩行原画とは一部に違いがあります。半透明の毛先のアルファは緑背景からの推定です。

対応する旧版ランタイム `art_source/sprites.rle` の SHA256 は `6c3c1750aa22e650d36a19e3d43b9b77e5632093b5a6700932be13c4c03afffc`。旧フレーム4〜9に対応しますが、今回は欠けていた全身を原画から取り込み直すため、旧RLE画素の完全一致を目標にはしていません。
